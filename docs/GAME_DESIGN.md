# GAME DESIGN — Ngara Street Hustle

## One-line pitch
A stylised 3D business simulation where you start with KSh 500 and a
street food stall on Ngara, Nairobi, and build a real food business.

## Core fantasy
"I started with almost nothing and built a business through smart decisions."

## Not a cooking game
Cooking is one system. The game is about money, customers, reinvestment,
and growth — not reflex minigames.

## Starting state
- KSh 500 cash
- One small food stall
- Basic jiko (cooking equipment)
- Limited ingredients
- One product: chapati beans

## Core loop
Explore → buy ingredients → return to stall → cook → serve customers →
earn KSh → track profit → reinvest → upgrade → unlock → repeat.

## Tone
Grounded, warm, authentic Nairobi street life. Stylised realism.
Fictional businesses, real-feeling street.

## Success criterion for the first prototype (Phase 7)
A player can boot the game, buy ingredients, cook, serve at least one
customer, and see their balance change — all without refreshing.
