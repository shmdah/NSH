# Ngara Street Hustle (NSH)

A browser-based 3D business simulation set on a stylised Ngara street
in Nairobi. Start with KSh 500 and a food stall, and build a real
food business.

## Stack
HTML5 · CSS3 · JavaScript (ES modules) · Three.js · Vite · GSAP ·
LocalStorage · (Rapier later, if needed)

## Development

```bash
npm install
npm run dev
